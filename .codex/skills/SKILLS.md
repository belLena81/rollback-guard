# Codex Skills

Use these project-local skills when working on Rollback Guardian.

| Skill | Use When |
|---|---|
| `go-development/` | Implementing Go services, packages, adapters, or APIs. |
| `postgres-development/` | Designing, reviewing, or modifying PostgreSQL schemas, migrations, constraints, indexes, queries, or adapters. |
| `write-plan/` | Creating decision-complete implementation plans from specs. |
| `test-driven-development/` | Adding features, bug fixes, refactors, or state-machine changes. |
| `systematic-debugging/` | Investigating failures or unexpected behavior. |
| `review-checklist/` | Reviewing a change before commit or handoff. |
